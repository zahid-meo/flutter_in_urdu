Mobile application development mein user authentication (Login aur Registration) sab se zaroori hissa hota hai. Agar aap apna custom backend server (jaise Node.js ya Django) nahi banana chahte, to **Google Firebase** sab se fast, secure aur reliable solution hai.

Is step-by-step tutorial mein hum seekhenge ke Flutter app ke andar Firebase Email aur Password Authentication kaise integrate karte hain, taake aapke users apna account bana sakein aur safe tareeqay se login kar sakein.

---

## 1. Firebase Console Setup (Pehla Qadam)

Shuru karne se pehle hamen Firebase Console par project create karna hoga:

1. [Firebase Console](https://console.firebase.google.com/) par jayein aur apne Google account se sign in karein.
2. **Add project** par click karein aur project ka naam rakhein (e.g., `flutter-auth-urdu`).
3. Google Analytics ko enable karein ya skip kar dein, phir **Create Project** dabayein.
4. Left sidebar mein **Build** menu ke andar **Authentication** par click karein.
5. **Get Started** button dabayein aur **Sign-in method** tab mein se **Email/Password** ko select karke `Enable` toggle ko on karein aur `Save` kar dein.

## 2. Flutter Project Mein Firebase Packages Install Karna

Apne terminal mein apne Flutter project ke folder mein jayein aur zaroori packages install karein:

```bash
flutter pub add firebase_core firebase_auth
```

Iske baad `lib/main.dart` mein Firebase ko initialize karna zaroori hota hai:

```dart
import 'package:flutter/material.dart';
import 'package:firebase_core/firebase_core.dart';

void main() async {
  // Flutter bindings ko initialize karna zaroori hai async code se pehle
  WidgetsFlutterBinding.ensureInitialized();
  
  // Firebase initialize karein
  await Firebase.initializeApp();
  
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return const MaterialApp(
      debugShowCheckedModeBanner: false,
      home: LoginScreen(),
    );
  }
}
```

## 3. AuthService Class (Clean Architecture)

Best practice yeh hai ke Firebase ke tamam functions ko alag file `services/auth_service.dart` mein rakha jaye taake UI code saaf aur readable rahe:

```dart
import 'package:firebase_auth/firebase_auth.dart';

class AuthService {
  final FirebaseAuth _auth = FirebaseAuth.instance;

  // Current user stream (Auto login check karne ke liye)
  Stream<User?> get userStream => _auth.authStateChanges();

  // 1. New User Registration (Sign Up)
  Future<UserCredential?> signUpWithEmail({
    required String email,
    required String password,
  }) async {
    try {
      UserCredential credential = await _auth.createUserWithEmailAndPassword(
        email: email.trim(),
        password: password.trim(),
      );
      return credential;
    } on FirebaseAuthException catch (e) {
      throw _handleAuthException(e);
    }
  }

  // 2. User Login
  Future<UserCredential?> loginWithEmail({
    required String email,
    required String password,
  }) async {
    try {
      UserCredential credential = await _auth.signInWithEmailAndPassword(
        email: email.trim(),
        password: password.trim(),
      );
      return credential;
    } on FirebaseAuthException catch (e) {
      throw _handleAuthException(e);
    }
  }

  // 3. User Logout (Sign Out)
  Future<void> signOut() async {
    await _auth.signOut();
  }

  // Exception messages ko aasan Urdu/English mein convert karna
  String _handleAuthException(FirebaseAuthException e) {
    switch (e.code) {
      case 'user-not-found':
        return 'Is email par koi account nahi mila. Pehle signup karein.';
      case 'wrong-password':
        return 'Ghalat password darj kiya gaya hai.';
      case 'email-already-in-use':
        return 'Yeh email pehle se registered hai. Login karein.';
      case 'weak-password':
        return 'Password kam az kam 6 characters ka hona chahiye.';
      case 'invalid-email':
        return 'Email address ka format ghalat hai.';
      default:
        return e.message ?? 'Aik anjana error pesh aaya hai.';
    }
  }
}
```

## 4. Login & Registration Screen Ka UI Code

Ab hum aik practical Login screen banate hain jahan user apna email aur password enter kar sake:

```dart
import 'package:flutter/material.dart';
import 'auth_service.dart';

class LoginScreen extends StatefulWidget {
  const LoginScreen({super.key});

  @override
  State<LoginScreen> createState() => _LoginScreenState();
}

class _LoginScreenState extends State<LoginScreen> {
  final TextEditingController _emailController = TextEditingController();
  final TextEditingController _passwordController = TextEditingController();
  final AuthService _authService = AuthService();
  bool _isLoading = false;

  void _handleLogin() async {
    setState(() => _isLoading = true);
    try {
      await _authService.loginWithEmail(
        email: _emailController.text,
        password: _passwordController.text,
      );
      if (mounted) {
        ScaffoldMessenger.of(context).showSnackBar(
          const SnackBar(content: Text('Login Kamyab!')),
        );
      }
    } catch (e) {
      if (mounted) {
        ScaffoldMessenger.of(context).showSnackBar(
          SnackBar(content: Text(e.toString()), backgroundColor: Colors.red),
        );
      }
    } finally {
      if (mounted) setState(() => _isLoading = false);
    }
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Login - Muhammad Zahid Dev')),
      body: Padding(
        padding: const EdgeInsets.all(20.0),
        child: Column(
          mainAxisAlignment: MainAxisAlignment.center,
          children: [
            TextField(
              controller: _emailController,
              keyboardType: TextInputType.emailAddress,
              decoration: const InputDecoration(
                labelText: 'Email Address',
                border: OutlineInputBorder(),
              ),
            ),
            const SizedBox(height: 16),
            TextField(
              controller: _passwordController,
              obscureText: true,
              decoration: const InputDecoration(
                labelText: 'Password',
                border: OutlineInputBorder(),
              ),
            ),
            const SizedBox(height: 24),
            _isLoading
                ? const CircularProgressIndicator()
                : ElevatedButton(
                    onPressed: _handleLogin,
                    style: ElevatedButton.styleFrom(
                      minimumSize: const Size.fromHeight(50),
                    ),
                    child: const Text('Login Karein'),
                  ),
          ],
        ),
      ),
    );
  }
}
```

## 5. Common Errors Aur Unka Hal

1. **`[core/no-app] No Firebase App '[DEFAULT]' has been created`:**
   - **Wajah:** Aap ne `Firebase.initializeApp()` call nahi kiya ya `WidgetsFlutterBinding.ensureInitialized()` add karna bhool gaye.
   - **Solution:** `main()` method mein dono lines zaroor shamil karein.

2. **`email-already-in-use` Error:**
   - **Wajah:** User usi email se dobara signup karne ki koshish kar raha hai.
   - **Solution:** User ko friendly message dikhayein aur Login screen par redirect karein.

3. **Android par release build mein crash:**
   - **Wajah:** ProGuard rules ya internet permission missing hoti hai.
   - **Solution:** `android/app/src/main/AndroidManifest.xml` mein `<uses-permission android:name="android.permission.INTERNET"/>` shamil karein.

## 6. Meri Raaye / Mera Tajurba (Muhammad Zahid)

> **Mera Tajurba:**
> Aksar beginners direct UI ke andar `FirebaseAuth.instance` ko call kar lete hain. Yeh tareeqa choti apps ke liye theek lagta hai lekin jab project bara hota hai to test karna aur manage karna bohat mushkil ho jata hai.
>
> Meri raaye yeh hai ke hamesha ek **AuthService** ya **Repository pattern** banayein. Is tarah agar kal ko aap Firebase se Supabase ya custom API par shift hon to aapko poori UI badalne ki zaroorat nahi paregi, sirf ek service class change hogi.
