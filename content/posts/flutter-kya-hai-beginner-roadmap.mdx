## 1. Flutter Kya Hai? (What is Flutter?)

Flutter Google ka banaya hua ek open-source **UI Software Development Kit (SDK)** hai. Iska sab se bara faida yeh hai ke aap sirf ek single codebase (ek hi dafa code likh kar) darj zail platforms ke liye apps bana sakte hain:
* Android Apps
* iOS Apps (iPhone / iPad)
* Web Applications
* Desktop Apps (Windows, macOS, Linux)

Flutter mein coding karne ke liye hum **Dart** programming language ka istemaal karte hain, jo ke Google ki hi banayi hui ek fast, object-oriented language hai.

### Flutter Doosray Frameworks Se Mukhtalif Kyun Hai?
Pehle cross-platform frameworks (jaise Cordova ya puraane hybrid tools) web-views ya JavaScript bridge ka sahara lete thay jis se apps slow aur laggy mehsoos hoti theen.

Lekin Flutter kisi bridge par depend nahi karta! Flutter ke paas apna rendering engine (**Impeller / Skia**) hai. Matlab screen par har ek pixel Flutter khud draw karta hai. Is wajah se Flutter apps ki performance bilkul Native apps (Kotlin ya Swift) jaisi smooth aur 60fps/120fps par chalti hai.

## 2. Flutter Ke Ahem Faide (Why Choose Flutter?)

1. **Hot Reload (Super Fast Coding):** Jab aap code mein koi tabdeeli karte hain, to app ko dobara band karke chalane ki zaroorat nahi hoti. Sirf `Ctrl + S` dabane se 1 second ke andar aapki mobile screen par changes nazar aa jati hain.
2. **Everything is a Widget:** Flutter ka poora philosophy widgets par mushtamil hai. Button, text, padding, row, column, yahan tak ke screen ka background bhi ek widget hai.
3. **Huge Community & Packages:** [pub.dev](https://pub.dev) par hazaron free open-source libraries mojood hain jahan se aap camera, Google Maps, Firebase, aur audio players asani se shamil kar sakte hain.
4. **AdSense & Monetization Friendly:** Flutter apps mein Google AdMob aur in-app purchases lagana intehai aasan hai.

## 3. Flutter Shuru Karne Ke Liye Zaroori Requirements (Prerequisites)

Flutter start karne se pehle aapke paas yeh basic cheezein honi chahiyein:
* **Operating System:** Windows 10/11 (64-bit), macOS, ya Linux
* **RAM:** Kam az kam 8GB RAM (16GB ho to Android Studio aur Emulator bohat smooth chalte hain)
* **Storage:** 15GB se 20GB free space
* **Basic Programming Knowledge:** Agar aapko C++, Java, ya OOP (Object Oriented Programming) ka basic pata hai, to Dart seekhna aapke liye 2 din ka kaam hai.

## 4. Step-by-Step Installation Guide (Windows)

Chaliye step by step setup karte hain:

### Step 1: Flutter SDK Download Karein
1. Official website [docs.flutter.dev](https://docs.flutter.dev) par jayein aur Windows ke liye latest Flutter SDK zip file download karein.
2. Is zip file ko `C:\src\flutter` directory mein extract karein. *(Note: Isay Program Files mein mat rakhein kyunke wahan administrator permissions ka masla banta hai).*

### Step 2: Environment Variables (Path) Add Karein
1. Windows Search mein `env` likhein aur **Edit the system environment variables** kholen.
2. **Environment Variables** button par click karein.
3. `User variables` ke andar **Path** ko select karke `Edit` dabayein.
4. `New` par click karke yeh path add karein: `C:\src\flutter\bin`.
5. `OK` karke close kar dein.

### Step 3: Flutter Doctor Run Karein
Apna Command Prompt ya PowerShell open karein aur type karein:

```bash
flutter doctor
```

Yeh command aapke system ko scan karegi aur batayegi ke kya kya cheezein install hain aur kya missing hain (jaise Android Studio ya Command-line Tools).

## 5. Aapka Pehla Flutter Code: "Hello World" App

Jab aapka Android Studio aur VS Code setup ho jaye, to naya project banane ke liye terminal mein yeh command chalayein:

```bash
flutter create my_first_app
cd my_first_app
```

Ab project ke andar `lib/main.dart` file open karein aur niche diya gaya simple code paste karein:

```dart
import 'package:flutter/material.dart';

void main() {
  runApp(const MyFirstApp());
}

class MyFirstApp extends StatelessWidget {
  const MyFirstApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      title: 'Muhammad Zahid Flutter Tutorial',
      theme: ThemeData(
        colorScheme: ColorScheme.fromSeed(seedColor: Colors.blue),
        useMaterial3: true,
      ),
      home: const HomeScreen(),
    );
  }
}

class HomeScreen extends StatelessWidget {
  const HomeScreen({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: const Text('Flutter Roman Urdu Tutorial'),
        backgroundColor: Colors.blueAccent,
        foregroundColor: Colors.white,
      ),
      body: Center(
        child: Column(
          mainAxisAlignment: MainAxisAlignment.center,
          children: const [
            Icon(Icons.flutter_dash, size: 80, color: Colors.blue),
            SizedBox(height: 16),
            Text(
              'Assalam-o-Alaikum! Flutter mein khush-aamdeed.',
              style: TextStyle(fontSize: 18, fontWeight: FontWeight.bold),
              textAlign: TextAlign.center,
            ),
            SizedBox(height: 8),
            Text(
              'Yeh aapka pehla chalne wala widget hai.',
              style: TextStyle(fontSize: 14, color: Colors.grey),
            ),
          ],
        ),
      ),
    );
  }
}
```

Is code ko run karne ke liye mobile ko USB cable se connect karein ya emulator open karke type karein:
```bash
flutter run
```
Mubarak ho! Aapki pehli Flutter application screen par live chal rahi hai.

## 6. Beginners Ke Common Errors Aur Unka Hal

Shuruati daur mein har student ko in 3 errors ka samna karna parta hai. Ghabrane ki bilkul zaroorat nahi, inka aasan hal yeh hai:

### Error 1: "Android license status unknown"
* **Kyun aata hai?** Android Studio install karne ke baad Google ke licenses accept nahi hote.
* **Hal:** Terminal mein yeh command chalayein aur har license par `y` (yes) press karte jayein:
```bash
flutter doctor --android-licenses
```

### Error 2: "Target of URI doesn't exist" ya package red line
* **Kyun aata hai?** Jab project ki dependencies download nahi hotin.
* **Hal:** Terminal mein command chalayein:
```bash
flutter pub get
```

### Error 3: Gradle Build Stuck / Taking Forever on first run
* **Kyun aata hai?** Pehli dafa Gradle ko internet se libraries download karni parti hain jo Pakistan mein slow internet ki wajah se waqt leti hain.
* **Hal:** Pareshan na hon aur terminal ko band na karein. Pehla build 5-10 minutes le sakta hai, agle tamam builds chand seconds mein honge.
